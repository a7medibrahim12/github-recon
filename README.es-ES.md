# github-recon :
La búsqueda de GitHub es una función bastante poderosa y útil que puede utilizarse para buscar datos sensibles en los repositorios. Una colección de "dorks" de GitHub puede revelar información personal y/o organizacional sensible, como claves privadas, credenciales, tokens de autenticación, etc. Esta lista pretende ser útil al realizar pruebas de penetración en sistemas.
# info :
La herramienta **github-recon** utiliza la mayoría de las palabras, extensiones y nombres de archivos mediante "dorks" de GitHub para acelerar el reconocimiento inicial de la organización objetivo. El reconocimiento es el paso más importante en cualquier proceso de prueba de penetración o búsqueda de vulnerabilidades y en la búsqueda de datos secretos. Proporciona al atacante cierto conocimiento sobre la organización objetivo.
Esta herramienta puede utilizarse junto con tu enfoque habitual de búsqueda de vulnerabilidades. La idea es verificar y recopilar información sobre la organización objetivo rápidamente, sin invertir mucho tiempo. Además, puede ayudarte a determinar un enfoque para encontrar victorias rápidas en el objetivo.



# ¿Cómo usar esta herramienta?
Paso 1: Descarga el archivo desde la sección de Releases: [Descargar herramienta](https://github.com/a7medibrahim12/github-recon/releases/download/v1.1.0/bughuntergithub.zip) y
[Video explicativo](https://github.com/user-attachments/assets/e5150d33-3826-43d8-9389-1b100ff32e09)

1. ***Escribe el dominio.***
2. ***Haz clic en cualquier palabra de cualquiera de las listas.***
3. ***Ahora serás redirigido a GitHub.***
